01 / engineering approach

AI starts with a reliable system, not a prompt

My work connects the probabilistic layer of language models with deterministic data pipelines, validation and operations. Each project starts from a real user problem and makes the model only one component in a system that can be measured and improved.

01

Ground the model

Retrieve the right context, constrain outputs and make evidence visible instead of relying on model confidence.

02

Engineer the workflow

Separate model judgment from deterministic validation, scheduling, state management and error handling.

03

Operate the product

Design around latency, cost, security, observability and feedback rather than stopping at a local prototype.

CASE 01
RAG applicationPrivate knowledge system

Fieldnote AI

A cited learning agent built from course notes, transcripts, portfolio material and professional knowledge.

Goal and purpose

Make a personal learning library conversational without losing the connection to its original evidence. The assistant can use general model knowledge, but personal claims and course-specific answers remain traceable to retrieved sources.

USER OUTCOMEAsk one question. Receive a concise answer with inspectable evidence.

AI engineering concepts demonstrated

01Embeddings

Represent semantic meaning as vectors for similarity search.

02RAG

Retrieve external knowledge before generating an answer.

03Grounding

Connect generated claims to validated source citations.

04Model routing

Choose private local inference or faster cloud generation.

05Agent contract

Share role, boundaries and answer policy across models.

06Prompt security

Treat retrieved text as untrusted data, never instructions.

CASE 02
Agentic workflowAI + data engineering

GravelRadar

An autonomous data and SEO system for a global directory of gravel cycling events.

Goal and purpose

Keep a global event database accurate and discoverable without turning every update into manual research. Specialized agents find, validate and enrich event information while deterministic workflows control publication.

PRODUCT OUTCOMEA continuously maintained event product with a measurable search feedback loop.

AI engineering concepts demonstrated

01Agent specialization

Separate discovery, quality and SEO responsibilities.

02Structured outputs

Constrain generated data with explicit schemas.

03Model tiering

Match model capability and cost to each task.

04Tool use

Connect agents to web, PageSpeed and search data.

05Orchestration

Schedule ordered workflows with deterministic control.

06Feedback loops

Use production measurements to prioritize new work.
