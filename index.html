GravelRadar

Autonomous multi-agent platform for gravel cycling events

The problem

A global directory of gravel races needs fresh, accurate event data and organic traffic — two things that don't scale manually.

The system

Three autonomous LLM agents — discovery, quality and SEO — run daily on a schedule, coordinated by a promoter. They discover events from the web, validate them against schemas, author SEO content, and measure the results through a closed feedback loop.

The loop

measure → prioritize → act → verify → update
